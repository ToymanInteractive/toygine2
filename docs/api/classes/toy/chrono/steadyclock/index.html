Description​

Monotonic clock over the highest-resolution steady counter of the active platform.

Stateless facade: every method is static and reads the platform counter directly. The epoch is unspecified, so only differences of readings taken within one process carry meaning.

Key Features​

Monotonic: readings never step back within a process, whatever the system does to wall-clock time. Nanosecond unit: toy::chrono::SteadyClock::period is fixed by toy::chrono::steadyClockPeriodDenominator. Tick access: nowTicks() and frequency() expose the raw counter for arithmetic without a duration conversion. No allocation: a reading is a platform counter read plus integer arithmetic. Exception safety: no operation throws; exceptions are off in the build.

Usage Example​

 #include "core.hpp"
 
 const auto frameStart = toy::chrono::SteadyClock::now();
 // ... frame work ...
 const auto frameDelta = toy::chrono::SteadyClock::now() - frameStart;

Performance Characteristics​

Reading: O(1); one platform counter read, plus integer arithmetic where the counter ticks at a native rate. Memory usage: no state; the class is never instantiated.

Safety Guarantees​

Contracts: none on the reading side; initialize() runs before the application starts. Thread safety: every method reads the counter and state written once at startup, so any thread may call them. Determinism: readings differ between runs and targets; replay and rollback record inputs, not re-read ticks. Memory safety: nothing allocates. Exception safety: no operation throws; exceptions are off in the build.

Compatibility​

Backed by CLOCK_MONOTONIC_RAW on macOS and Linux and by QueryPerformanceCounter on Windows. The console targets link a stub: ticks stay 0 until their real counter backends land.
