Description​

Wall clock returning the local date and time as broken-down fields.

Reads the platform's real-time source where one exists and synthesizes a value from the process uptime elsewhere. Every target returns a usable toy::chrono::CalendarTime; no reading is a sentinel. Adjustments of the system time move the readings, so spans measured across them belong to toy::chrono::SteadyClock.

Key Features​

Local reading: fields carry local time and the offset from UTC, ready for display. Always usable: targets without an RTC return the value toy::chrono::CalendarTime::fromUptime() synthesizes instead of an invalid marker. Stateless: the single method is static; the class is never instantiated. Exception safety: no operation throws; exceptions are off in the build.

Usage Example​

 #include "core.hpp"
 
 const toy::chrono::CalendarTime calendar = toy::chrono::SystemClock::now();

Performance Characteristics​

Reading: O(1); platform time calls, no loops over data. Memory usage: no state; the result is 12 bytes.

Safety Guarantees​

Contracts: none; the platform startup order covers the synthesis (see toy::chrono::initialize()). Thread safety: every call reads the platform time source independently. Determinism: readings differ between runs and targets; never feed them into simulation state. Memory safety: nothing allocates. Exception safety: no operation throws; exceptions are off in the build.

Compatibility​

macOS and Linux read clock_gettime(CLOCK_REALTIME) with localtime_r; Windows reads GetLocalTime with GetTimeZoneInformation. The console targets synthesize from the uptime through toy::chrono::CalendarTime::fromUptime(); on the stub backends the uptime is zero, so the reading is the all-zero base.
