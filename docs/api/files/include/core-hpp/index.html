Description​

Umbrella header for the engine core module.

Single public entry point for the core module: aggregates its public headers into namespace toy, re-exports the standard-library names the engine builds on, and defines the assert and assert_message macros.

info

Include this header only; do not include internal headers directly.

Macro Definitions​

__FUNC_SIGNATURE__​

#define __FUNC_SIGNATURE__   __func__

Name of the enclosing function, as the active compiler spells it.

Expands to __FUNCSIG__ on MSVC, to __PRETTY_FUNCTION__ on GCC and Clang, and to __func__ elsewhere, so a failure report carries the full signature where the compiler offers one.

info

Defined only when _DEBUG is defined, and expanded by assert and assert_message; call sites never spell it.

assert​

#define assert(expression)   ...

Checks expression in a debug build and reports a failure with its source location.

Value
do { \   if (!(expression)) { \     if (std::is_constant_evaluated()) { \       toy::assertion::assertCompileTimeError(); \     } else { \       toy::assertion::assertion(#expression, nullptr, __FILE__, __FUNC_SIGNATURE__, __LINE__); \     } \   } \ } while (0)

Passes the expression as written, the file, the enclosing function, and the line to toy::assertion::assertion(), which reports the failure through the registered toy::assertion::AssertionCallback. A failure during constant evaluation calls toy::assertion::assertCompileTimeError() instead, which makes the enclosing constant expression non-constant and fails the build.

Parameters
expression

Condition that must hold. Evaluated once, and only in a debug build.

Precondition

toy::assertion::initialize() has been called; without it a failure reports nothing.

info

Execution continues past a failed check: the macro reports it and returns, so stopping is the registered handler's own decision.

info

Replaces the assert macro of <cassert>, which this header undefines first.

info

Compiled in only when _DEBUG is defined. Every other build expands to ((void)0), so expression is never evaluated and a side effect written inside it is lost.

assert_message​

#define assert_message(expression, message)   ...

Checks expression in a debug build and reports a failure with message and its source location.

Value
do { \   if (!(expression)) { \     if (std::is_constant_evaluated()) { \       toy::assertion::assertCompileTimeError(); \     } else { \       toy::assertion::assertion(#expression, message, __FILE__, __FUNC_SIGNATURE__, __LINE__); \     } \   } \ } while (0)

Routes the failure exactly as assert does, with message carried into the description so that a report reads without opening the source.

Parameters
expression

Condition that must hold. Evaluated once, and only in a debug build.

message

Reason the condition must hold, in human-readable form, or nullptr for none. Read during the call only.

Precondition

toy::assertion::initialize() has been called; without it a failure reports nothing.

info

Compiled in only when _DEBUG is defined. Every other build expands to ((void)0), so neither argument is evaluated.
