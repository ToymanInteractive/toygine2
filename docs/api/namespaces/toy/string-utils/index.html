Description​

Search and comparison over a character range that a pointer and a length describe.

A function reads only the characters inside the range: it needs no terminator after them, and a '\0' inside counts as an ordinary character. Characters compare as bytes with no locale, so a result is identical across runs and targets. Every function works in a constant expression and allocates nothing. A sequence or set search takes O(n * m) comparisons in the worst case, in the length of the range and of the pattern or set; the rest take O(n).

compare()​

int toy::string_utils::compare (const char * lhs, size_t lhsSize, const char * rhs, size_t rhsSize)
 nodiscard constexpr noexcept

Compares the lhsSize bytes starting at lhs with the rhsSize bytes starting at rhs in lexicographic order.

Compares bytes as unsigned char up to the shorter length; when one range is a prefix of the other, the shorter one orders first. A '\0' inside either range compares like any other byte.

Parameters
lhs

First byte of the left range.

lhsSize

Number of bytes in the left range.

rhs

First byte of the right range.

rhsSize

Number of bytes in the right range.

Returns

A negative value when the left range orders first, 0 when both hold the same characters, a positive value when the right range orders first.

Precondition

lhs is non-null or lhsSize is 0, checked by assert_message in debug builds.

Precondition

The lhsSize bytes starting at lhs are readable.

Precondition

rhs is non-null or rhsSize is 0, checked by assert_message in debug builds.

Precondition

The rhsSize bytes starting at rhs are readable.

info

Only the sign carries meaning; the magnitude is whatever the byte comparison produced.

size_t toy::string_utils::find (const char * data, size_t size, const char * pattern, size_t pos, size_t count)
 nodiscard constexpr noexcept

Finds the first position at or after pos where the count bytes starting at pattern start.

Matches the bytes of pattern in order and next to each other; toy::string_utils::findFirstOf() matches any one of them. Reads exactly count bytes of the pattern, so it needs no terminator and may hold '\0'.

Returns
