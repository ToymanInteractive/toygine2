String()​

template <std::input_iterator InputIterator>
toy::String< storageType >::String (InputIterator first, InputIterator last)
 constexpr noexcept

Builds a string from a copy of the characters in [first, last).

A forward range is measured first and copied in one step, so the storage is asked for the whole length once; a pair of pointers is measured by subtraction and copied as one block. A single-pass range is read one character at a time, each checked against the storage before it is written.

Template Parameters
InputIterator

Iterator type with char as its value type; satisfies std::input_iterator and is its own std::sentinel_for.

Parameters
first

Iterator to the first character to copy.

last

Iterator past the last character to copy.

Precondition

last is reachable from first.

Precondition

The storage accepts the length of the range, checked by assert_message in debug builds.

Postcondition

size() returns the length of the range, and c_str() reads its characters followed by '\0'.

info

A forward range without subtraction, such as a linked list, is traversed twice: once to measure, once to copy.

warning

A shipping build skips the capacity check and leaves the string empty when the storage rejects the length of the range.

template <StringLike StringType>
toy::String< storageType >::String (const StringType & string, size_type pos, size_type count=npos)
 constexpr noexcept

Builds a string from a copy of the substring of string that starts at pos.

Takes at most count bytes and stops at the end of string. Covers the std::basic_string substring constructors from a string and from a string-view-like type, a toy::String of any storage included. With a pointer the same call shape means a prefix: String("player", 2) holds "pl", while String(StringView("player"), 2) holds "ayer".

Template Parameters
StringType

Source type; satisfies toy::StringLike.

Parameters
string

View or string to copy from.

pos

Offset of the first byte to copy.

count

Most bytes to copy (default: toy::String::npos, which copies to the end of string).

Precondition

pos is not greater than the length of string, checked by assert_message in debug builds.

Precondition

The storage accepts the length of the substring, as String(const char *, size_t) requires.

Postcondition

size() returns the smaller of count and the length of string minus pos, and c_str() reads those bytes followed by '\0'.

Prepares the storage to hold newCapacity characters without growing again.

Passes the request to the storage: toy::FixedStringStorage checks it against its buffer and allocates nothing, while a storage that owns heap memory may allocate here. A request no greater than capacity() keeps the buffer where it is, and no request shrinks it, as in std::basic_string since C++20.

Parameters
newCapacity

Precondition

The storage accepts newCapacity: its reserve() returns true, checked by assert_message in debug builds.

info

A request above capacity() may move the buffer, so pointers and iterators into the string must be taken again.

warning

A shipping build skips the check and leaves the string unchanged when the storage rejects newCapacity, where std::basic_string throws std::length_error.

_mayOverlap()​

template <StringStorage storageType>
bool toy::String< storageType >::_mayOverlap (const_pointer pointer)
 nodiscard constexpr noexcept

Reports whether a source starting at pointer may share bytes with the storage.

Tells an assignment whether it needs memmove() or can use memcpy(). Constant evaluation cannot compare pointers into unrelated objects, so it answers true there, and the caller takes the copy that tolerates overlap.

Parameters
pointer

First byte of the source.

Returns

true when pointer lies within the buffer, its terminator included, or during constant evaluation; false otherwise.

info

Only the first byte is checked; a source that starts before the buffer and runs into it is not a valid string.
