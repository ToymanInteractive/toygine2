operator<=>()​

StringView::traits_type::comparison_category toy::operator<=> (StringView lhs, StringView rhs)
 constexpr noexcept

Reads the bytes in order and settles a tie on the lengths, so a string that starts another one orders before it. Either side converts from a null-terminated byte string, as equality does.

Parameters
lhs

View on the left of the operator.

rhs

View on the right of the operator.

Returns

std::strong_ordering::less when lhs orders first, std::strong_ordering::equal when both hold the same characters, std::strong_ordering::greater when rhs orders first.

info

The compiler synthesizes <, <=, >, and >= from this operator.

info

Bytes order by their unsigned char value, so the order holds on a target whose plain char is signed.

info

The order consults no locale, which makes it identical across runs and targets.

utf8Len()​

size_t toy::utf8Len (const char * str)
 nodiscard noexcept

Counts the characters a UTF-8 string encodes.

Walks the string one lead byte at a time and steps over the sequence that byte announces, so a character stored in two, three, or four bytes counts once. The walk trusts the width the lead byte announces; toy::validateUtf8() is what checks the bytes behind it.

Parameters
str

Null-terminated UTF-8 string to measure.

Returns

Count of encoded characters, 0 over an empty string, and 0 where the walk stops early.

Precondition

str is non-null, checked by assert_message in debug builds; a shipping build counts 0 instead.

Precondition

str holds well-formed UTF-8, checked with toy::validateUtf8() by assert_message in debug builds. A shipping build skips that check: a byte starting no sequence and a sequence the terminator cuts short each end the count at 0, while an overlong, a surrogate, and a code point past U+10FFFF each count as one character.

info

The count is a runtime one: the definition lives in a translation unit, out of reach of a constant expression.

info

The walk stops at the terminator and never reads past it, whatever width a lead byte announces.

validateUtf8()​

bool toy::validateUtf8 (const char * str)
 nodiscard noexcept

Reports whether a byte string is well-formed UTF-8.

Checks every sequence against Unicode table 3-7: the lead byte, the narrowed range of the byte after it, and the 10xxxxxx form of the rest. That rejects an overlong encoding, a surrogate, and a code point past U+10FFFF, each of which a lead byte alone admits.

Parameters
str

Null-terminated byte string to check.

Returns

true when every sequence is well-formed, false at the first that is not and false for a null str. An empty string is well-formed.

info

Asserts nothing, so it reads as the condition of an assert_message check — which is how utf8Len() states its precondition.

info

The check is a runtime one: the definition lives in a translation unit, out of reach of a constant expression.

info

Cost is O(n) in the length of the string, one pass, so a caller checking before a walk pays for two.
