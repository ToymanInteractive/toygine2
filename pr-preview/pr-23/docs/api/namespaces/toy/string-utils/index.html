Description​

Text utilities shared across the core types: character search and comparison, plus UTF-8 and UTF-16 conversion, counting, and validation.

A search or comparison function reads only the characters inside the toy::span it is given: it needs no terminator after them, and a '\0' inside counts as an ordinary character. Counting and validation also take a null-terminated string and walk it to its terminator. Characters compare as bytes with no locale, so a result is identical across runs and targets. No function allocates. Search, comparison, and toy::string_utils::utf8Size() work in a constant expression; every other function is a runtime one, defined in a translation unit. A sequence or set search takes O(n * m) comparisons in the worst case, in the length of the range and of the pattern or set; the rest take O(n).

 nodiscard constexpr noexcept

Compares lhs with rhs in lexicographic order.

Compares bytes as unsigned char up to the shorter length; when one range is a prefix of the other, the shorter one orders first. A '\0' inside either range compares like any other byte.

Parameters

rhs

Returns

Precondition

Precondition

info

utf16ToUtf8()​

char * toy::string_utils::utf16ToUtf8 (span< char > dest, span< const char16_t > src)
 noexcept

Converts a range of UTF-16 units to a null-terminated UTF-8 string in a caller-supplied buffer.

Encodes a unit outside the surrogate range as one to three bytes and a surrogate pair as one four-byte sequence, so the result is well-formed UTF-8. Only the length of src bounds the input, so a u'\0' inside the range comes out as '\0' in dest. Allocates nothing; the result is always null-terminated.

Parameters
dest

Buffer that receives the UTF-8 string; its size is the capacity, terminator included.

src

UTF-16 units to convert. An empty range, or one whose data pointer is nullptr, encodes nothing.

Returns

dest.data(), or nullptr when dest is empty or names no data; dest is then left untouched.

Precondition

Every code unit of src is readable.

Postcondition

dest holds the encoded characters from the start of src, followed by '\0'. Encoding stops at the end of the range, before a character that does not fit whole in one less than the capacity of dest, and before a surrogate whose pair does not lie whole inside the range.

info

Truncation and lone surrogates go unreported: a buffer of toy::string_utils::utf16InUtf8MaxSize bytes per unit of the range, plus one for the terminator, holds every character the call encodes.

info

The conversion is a runtime one: the definition lives in a translation unit, out of reach of a constant expression.

validateUtf8()​

bool toy::string_utils::validateUtf8 (const char * str)
 nodiscard noexcept

Reports whether a byte string is well-formed UTF-8.

Checks every sequence against Unicode table 3-7: the lead byte, the narrowed range of the byte after it, and the 10xxxxxx form of the rest. That rejects an overlong encoding, a surrogate, and a code point past U+10FFFF, each of which a lead byte alone admits.

Parameters
str

Null-terminated byte string to check.

Returns

true when every sequence is well-formed, false at the first that is not and false for a null str. An empty string is well-formed.

info

Asserts nothing, so it reads as the condition of an assert_message check, which is how toy::string_utils::utf8Len() states its precondition.

info

The check is a runtime one: the definition lives in a translation unit, out of reach of a constant expression.

info

Cost is O(n) in the length of the string, one pass, so a caller checking before a walk pays for two.

validateUtf8()​

bool toy::string_utils::validateUtf8 (span< const char > str)
 nodiscard noexcept

Reports whether str holds well-formed UTF-8.

Runs the checks of toy::string_utils::validateUtf8(const char *) over a range bounded by the span's length, not by a terminator. Reads no byte past the range, and a '\0' inside it counts as a one-byte character.

Parameters
str

Range of bytes to check.

Returns

true when every sequence is well-formed and ends inside the range, false at the first that is not. An empty range is well-formed, a null str included.

Precondition

Every byte of str is readable, and a null str comes with an empty range, checked by assert_message in debug builds.

info

The check is a runtime one: the definition lives in a translation unit, out of reach of a constant expression.

info

Cost is O(n) in the range length, one pass.

warning

A shipping build skips the null check and answers false to a null str that carries bytes.

See Also
