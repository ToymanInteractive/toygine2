Description​

Measures the span elapsed since its construction or last reset().

A declaration starts the measurement: the default member initializer records the start ticks. Copying fixes the same starting point, so a copy reports the original span, not a fresh one.

Key Features​

Starts on declaration: no start call; constructing the value records the starting counter reading. Restartable: reset() moves the starting point to the current counter reading. Two readings: elapsed() as a duration, elapsedTicks() as the raw tick difference. Value semantics: trivially copyable; a copy shares the recorded starting point. Exception safety: no operation throws; exceptions are off in the build.

Usage Example​

 #include "core.hpp"
 
 const toy::chrono::Stopwatch watch;
 // ... measured work ...
 const auto elapsed = watch.elapsed();

Performance Characteristics​

Reading: O(1); one counter read, a subtraction, and a conversion where the counter does not tick in nanoseconds. Memory usage: 8 bytes, the start tick alone.

Safety Guarantees​

Contracts: none; the platform startup order covers the counter (see toy::chrono::initialize()). Thread safety: reading one instance from several threads is safe; reset() writes the start tick and needs external ordering against concurrent readers. Determinism: readings differ between runs and targets; never feed them into simulation state. Memory safety: nothing allocates. Exception safety: no operation throws; exceptions are off in the build.

Compatibility​

On the stub console targets the counter stays at zero, so every reading is zero until real backends land.
