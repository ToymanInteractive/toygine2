Duration​

Time span of Rep ticks, each Period of a second long.

Alias of std::chrono::duration with no runtime behavior of its own; every operation of the standard template applies.

Arithmetic type of the tick count, or a class emulating one.

TimePoint​

template <typename Clock, typename Dur = typename Clock::duration>
using toy::chrono::TimePoint = std::chrono::time_point<Clock, Dur>

Instant on Clock's timeline, stored as a Dur since the clock's epoch.

Alias of std::chrono::time_point. Subtracting two points of one clock yields a toy::chrono::Duration; the epoch itself is whatever the clock defines.

Template Parameters
Clock

Clock type whose epoch the point counts from; satisfies the CppClock requirements.

Dur

toy::chrono::Duration measuring the offset from the epoch (default: the clock's own duration).

Functions​

initialize()​

void toy::chrono::initialize ()
 noexcept

Prepares the clock backend and fixes the origin toy::chrono::Timestamp::now() counts from.

Caches the counter frequency where the platform reports it at runtime and records the start ticks. The engine calls it once at startup, before the application body runs; a program with its own entry point calls it there instead.

Postcondition

toy::chrono::Timestamp::now() counts from this call; on Windows frequency() reports the cached counter frequency.

к сведению

Calling it again restarts the timestamp origin and breaks the ordering of stamps taken across the call.

steadyClockPeriodDenominator​

int64_t toy::chrono::steadyClockPeriodDenominator = platform::detail::steadyClockPeriodDenominator
 constexpr

Ticks per second of the toy::chrono::SteadyClock duration, fixed by the active target.

The denominator of the tick period: 1'000'000'000 on every target, so a duration tick is one nanosecond. Each target sets the value in the platform_config.hpp of its directory under src/platforms; native console tick periods arrive with the real counter backends.
