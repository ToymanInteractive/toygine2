Description​

Local date and time split into calendar fields, with the offset from UTC.

What toy::chrono::SystemClock::now() returns: the platform's local reading on the desktop targets, a value synthesized by fromUptime() where no RTC exists. Field ranges follow the platform reading; the synthesized value uses the conditional calendar fromUptime() documents.

Key Features​

Aggregate initialization: no constructor; designated initializers name the fields, and an omitted one is zero. Constexpr support: comparison and fromUptime() evaluate in a constant expression. Trivially copyable: a copy is a byte copy of the twelve bytes. Complete reading: the offset from UTC travels with the fields, so a consumer can reconstruct the instant. Exception safety: no operation throws; exceptions are off in the build.

Usage Example​

 #include "core.hpp"
 
 const toy::chrono::CalendarTime calendar = toy::chrono::SystemClock::now();
 const auto year = calendar.year;

Performance Characteristics​

Construction: O(1); fields are stored as given. Access: O(1); every field is read directly. Memory usage: 12 bytes, alignment 2.

Safety Guarantees​

Contracts: none on the fields; fromUptime() checks its input with assert_message in debug builds. Type safety: fixed-width fields carry unit-bearing values, not a formatted string. Memory safety: nothing allocates, and the value owns nothing outside its fields. Exception safety: no operation throws; exceptions are off in the build.

к сведению

A default-constructed value is all zeros, which is the base of the synthesis, not a valid calendar date.

Public Static Functions​

fromUptime()​

CalendarTime toy::chrono::CalendarTime::fromUptime (Duration< int64_t, std::milli > uptime)
 nodiscard constexpr noexcept static

Splits an uptime into calendar fields over a conditional 360-day calendar.

Counts from an all-zero base: months hold 30 days and years hold 12 such months, so a reading never looks like a valid current date. toy::chrono::CalendarTime::dayOfWeek and toy::chrono::CalendarTime::tzOffsetMinutes stay 0. toy::chrono::SystemClock calls it on targets without an RTC.

Parameters
uptime

Milliseconds elapsed since the process started.

Returns

Fields of uptime laid over the zero base.

Precondition

uptime is non-negative, checked by assert_message in debug builds.

Precondition

The year computed from uptime fits int16_t, checked by assert_message in debug builds.

к сведению

Works in a constant expression.
